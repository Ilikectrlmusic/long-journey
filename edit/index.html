CONNECT TO GITHUB

把记录存到云端

仅仓库主人可以编辑。连接后，手机和电脑都能读取同一份记录。

  1. 在 GitHub 创建一个仅用于此站点的密钥。打开 GitHub 创建页面 ↗
  2. Repository access 选择 Only select repositories，只选 long-journey。
  3. 确认 Repository permissions 中 Contents 为 Read and write，然后生成密钥并粘贴到下方。

密钥仅用于直接连接 GitHub，不会写进仓库。不勾选时仅在当前浏览器会话保留；共享设备请在用完后断开连接。
